## Monitoring Rules

- Open programs with exact deadlines use active checks through the deadline.
- Interest-only routes never generate an "application opened" alert without a new official application page.
- Prior-cycle pages remain visible as watch-only when the program is still officially documented.
- Direct application URLs are used for student actions. When a direct application page exposes clearer current-cycle timing than the overview page, it is also used as the monitoring source.
